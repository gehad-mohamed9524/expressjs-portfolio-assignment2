    About the project

A portfolio website developed using Node.js, ExpressJS, EJS, and Bootstrap. The website showcases my background, technical skills, and academic projects in Networking and IT Security
This project builds on my original HTML and CSS portfolio from Assignment 1, transforming it into a dynamic web application using ExpressJS and EJS templates.
It uses Express routing to navigate between pages and reusable EJS partials to maintain a consistent layout.

    Website Features
- Home: A brief introduction to my portfolio.
- About Me: My background, technical skills, and introduction video.
- Projects: Academic projects with descriptions, images, and downloadable files.
- Contact Me: A contact form and contact information.
- Responsive Design: Bootstrap styling for different screen sizes.

    Technologies Used
- Node.js 
- ExpressJS 
- EJS 
- Bootstrap 
- HTML & CSS 

    Project Structure
- routes/ – Express route definitions
- views/ – EJS page templates
- views/partials/ – Shared header, navigation bar, and footer
- public/ – CSS, images, videos, and downloadable project files
- app.js – Express application configuration
